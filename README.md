# Vanilla Virtual Tour Presentation

افتح `index.html` مباشرة من المتصفح. لا يحتاج المشروع إلى Framework أو خطوات بناء.

## الملفات المطلوبة داخل assets

- `abaad-logo.png` شعار أبعاد العراق المستخدم في الشريط العلوي.
- `dot-logo.png` شعار DOT المستخدم في الشريط العلوي.
- `hero-vanilla-tour.jpg` صورة الهيرو الرئيسية بحجم عريض Edge-to-edge.
- `Cairo.woff2` ملف خط Cairo المحلي، اختياري إذا أردت تشغيل الخط بدون إنترنت.
- `hotspots-preview.jpg` صورة قسم النقاط الذكية.
- `tour-shot-01.jpg`
- `tour-shot-02.jpg`
- `tour-shot-03.jpg`
- `tour-shot-04.jpg`
- `tour-shot-05.jpg`
- `tour-shot-06.jpg`
- `vanilla-vr-experience.jpg` صورة تجربة VR للبوثات.

إذا لم تكن الملفات موجودة، سيعرض الموقع Placeholder واضحاً باسم الملف المطلوب بدلاً من عنصر مكسور.

## ملاحظات التعديل

- كل الصور المحلية موضحة بتعليقات داخل `index.html` فوق مكان استخدامها.
- يمكن استبدال ملفات الصور والفيديو داخل `assets` دون تعديل التصميم.
- الجولات الافتراضية لا تُحمّل تلقائياً؛ اضغط زر `تشغيل الجولة` داخل كل كارد.
